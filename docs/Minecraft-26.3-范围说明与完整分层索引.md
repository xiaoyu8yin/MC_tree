## 分层方法及非树状关系

第 1 层为“配方系统边界材料”：没有固定产出配方的材料，以及可外部取得、用于打开压缩/解压循环的原料，例如原木、矿物、骨头、白色羊毛、锻造模板。边界包括经过未纳入机制加工的物品，不声称均为未经加工的自然原料。模板的第一次获取必须靠战利品或其他游戏机制。

输入组之间全部需要（AND）；每个输入位置的候选可任选其一（OR），重复位置允许混用候选。L(配方产出)=1+max(各输入位置候选的最小层级)。同一物品多条配方取最早可达层级。边界节点固定为第 1 层。全部节点可达，没有未解析材料标签。

真实关系是含循环的有向超图。依赖树是浏览投影，路径重复时显示回链。替代配方可来自更高层；层级不代表游戏进度、开局可获得性或难度。全部输入没有齐备前，单一原料不能独自合成多输入产物。

数量按普通配方一次操作记录，不自动累乘为目标数量或总原料成本。酿造按单瓶转换建立关系，同批可处理多瓶，试剂数量不作为批次成本。工作站、燃料、工具耐久和返还容器未计入递归消耗；酿造台另需烈焰粉供能。原始 JSON 保留组件和条件供查证。
