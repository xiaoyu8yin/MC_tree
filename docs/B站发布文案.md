标题：我把 Minecraft 的合成配方，做成了一棵 3D 树

简介：
如果把 Minecraft 的合成关系种成一棵树，会是什么样？

这次用七个层级展示 1,491 个物品与独立药水状态。平时隐藏连线，选中一个物品后，才展开它的前置合成路径。不同层级使用不同颜色，流动光点指示从材料到产物的方向。

视频演示了胡萝卜钓竿和活塞两条路径，以及旋转视角、树干树根装饰和聚焦当前路径的效果。

数据范围：Minecraft Java 26.3；层级表示本图中的依赖关系，不代表游戏进度。第一层包含需要从配方范围之外取得的材料。演示展示一组代表性配方和替代材料，并非同时展示所有可能路径；多输入合成属于依赖图，并不是严格的树。

本片基于项目数据制作，为演示动画；配乐为本次生成的合成器音乐，无人声解说。
